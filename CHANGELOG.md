# Changelog

All notable changes below are taken from git history and release tags. Dates use the tag or commit date.

## [0.4.2] - 2026-08-23

Current public Beta (`v0.4.2`).

### Added

- Text tool (the feature landed in 0.4.1; this tag is the current Beta that includes it)

## [0.4.1] - 2026-08-23

### Added

- Text tool with Russian and English UI strings (plain text and arrow/pointer text)

## [0.4.0-beta.1] - 2026-08-23

### Added

- Leader / elevation annotation workflow (elevation marks; Alt+right-click returns to Select)
- Wide diagonal fill pattern

### Improved

- Dimension, axis, and offset snapping
- PDF physical lineweights for axes and dimensions
- Leader text scaling with the elevation mark on large drawings
- PDF preview fit and annotation text spacing
- Dimension, snap, and axis-offset performance
